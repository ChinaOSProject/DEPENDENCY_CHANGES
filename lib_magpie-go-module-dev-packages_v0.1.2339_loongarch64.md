# Magpie Go module development packages v0.1.2339 (loongarch64)

Adapted repository: [ChinaOSProject/magpie](https://github.com/ChinaOSProject/magpie)

This report covers the Go module source packages used to build Magpie v0.1.2339 CLI plus embedded Web (`nogui`). The package group passed isolated installation and source compilation checks and main-agent artifact review. The published Magpie report `magpie_v0.1.2339_loongarch64.md` was not edited.

## Accepted artifacts

The final candidate set is in `/tmp/magpie-20261031/module-final-20261105/generation-009/`:

- 47 `Architecture: all` Debian packages containing 50 unmodified Go modules.
- Package paths, Debian versions, sizes, and SHA256 values: `package-list.tsv` and `deb/SHA256SUMS`.
- Full package manifest and direct import relationships: `manifest.json`.
- Consolidated acceptance result: `acceptance.json`.
- Package metadata, payload, license, and path ownership checks: `artifact-audit.json`.

The main Agent accepted the exact generation-009 bytes and copied all 47 packages to `binaries/<package>/all/`, with individual SHA256 sidecars. The release inventory below records the canonical paths; the original task candidates and validation logs are retained.

## Files, licenses, and ownership

Each package installs its unchanged module source under `/usr/share/gocode/src/<module>`. Each module's upstream `LICENSE`, `COPYING`, `COPYRIGHT`, `NOTICE`, or `PATENTS` files are retained in the source tree, and their complete text is copied into that Debian package's `/usr/share/doc/<package>/copyright`.

The generation-009 artifact audit checked all 47 `.deb` hashes and control fields, verified direct `Depends` versions against the import graph, confirmed every license text block and source license file, checked that staged payload files exist in the `.deb`, and found zero non-directory file ownership collisions. After installation, all 50 module roots resolve to the expected Debian package owner; 12,424 installed source files were byte-compared with their candidate stages.
