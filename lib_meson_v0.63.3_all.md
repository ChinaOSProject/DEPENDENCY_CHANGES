Upstream project: https://github.com/mesonbuild/meson

Its SHA256 is 859a9529fedfe2b59e85f7d8c904339789306d74fe59c4b03e46d164d445ddf8. The previous loongarch64 candidate was withdrawn. The package follows Debian's Architecture all, Multi-Arch foreign model for Meson as a Python build tool. Debian's packaging and dependencies are documented in [Debian meson 1.0.1-5 packaging control](https://sources.debian.org/src/meson/1.0.1-5/debian/control) and [the source package](https://packages.debian.org/source/bookworm/meson). We retain ninja-build (>= 1.6) and add the Debian Python runtime modules used by Meson's Python project support: python3 (>= 3.7), python3-distutils, python3-pkg-resources, and python3-setuptools. dpkg-dev is recommended as in Debian packaging. The newer Debian control is a packaging reference; Meson 0.63.3 itself declares Python 3.7 as its floor. There are no architecture-specific ELF files and no GLib runtime files in this package.
